# XZONA Group Bot v8.2.1

## Исправление single-message интерфейса

- Исправлено накопление сообщений-подсказок во время ввода данных кладовщиком.
- Если Telegram не позволяет отредактировать рабочее сообщение, бот сначала удаляет старый экран и только потом создаёт новый.
- При запуске новой формы бот пытается удалить незавершённый старый prompt текущего FSM-сеанса.
- После добавления предмета, приёма имущества, выдачи имущества, создания/переименования раздела бот сразу возвращает то же рабочее сообщение в меню «Раздел кладовщика».
- Для завершённых складских операций больше не создаются отдельные сообщения «операция выполнена».
- Кнопка «Отмена» для основных экранов склада возвращает прямо в рабочее меню/склад вместо создания отдельной карточки статуса.
- Пользовательские сообщения ввода по-прежнему удаляются после обработки.

Примечание: сообщения, созданные старыми версиями бота до установки v8.2.1, Bot API не может обнаружить задним числом без сохранённых message_id. Их достаточно удалить один раз вручную; новые хвосты после обновления создаваться не должны.
