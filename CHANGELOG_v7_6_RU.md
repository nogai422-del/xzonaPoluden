# Изменения v7.6

- Полностью отключено автоматическое определение forum topics.
- Каждый раздел считается активным только после ручной команды `/set_..._topic` внутри нужной темы.
- Старые авто-привязки из предыдущих версий не используются, пока раздел не подтверждён вручную в v7.6.
- Если модуль переносится в другую тему, старая постоянная панель этого модуля удаляется, чтобы не оставлять ложные инструкции.
- Telethon теперь синхронизирует текущий состав основной группы.
- В БД добавлен отдельный реестр `group_members`: участник Telegram не становится игроком XZONA, пока не зарегистрирует игровой ник.
- При синхронизации обновляются Telegram username/имя уже зарегистрированных игроков, новые участники отмечаются, ушедшие сохраняются как история.
- В `/admin -> Telethon` добавлены кнопки `Синхронизировать участников` и `Состав группы`.
- В панели Telethon отображается количество текущих участников, сколько из них зарегистрировали игровой ник и время последней синхронизации.
- Добавлена автоматическая периодическая синхронизация состава. Интервал задаётся `TELETHON_MEMBER_SYNC_INTERVAL`, по умолчанию 3600 секунд; `0` отключает автоматическую синхронизацию.
