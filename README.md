# XZONA Group Bot — MVP

Telegram-бот для игровой группы XZONA.

## Что уже сделано

- регистрация игрока по Telegram ID + игровой ник;
- изменение собственного ника через `/nickname`;
- роли администратора через `ADMIN_IDS`;
- раздел «Хранилище»;
- ручной ввод предмета;
- запоминание недавно введённых названий;
- выбор владельца из зарегистрированных игроков;
- количество и необязательный комментарий;
- статус `На хранении`;
- выдача предмета с подтверждением;
- история выданных предметов;
- редактирование названия, количества и комментария;
- удаление активной записи;
- SQLite база данных создаётся автоматически.

## Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать `.env` рядом с `bot.py`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
DB_PATH=bot.db
```

`ADMIN_IDS` — Telegram ID администраторов. Узнать свой ID можно у любого бота, показывающего Telegram user ID.

Запуск:

```bash
python bot.py
```

## Логика первой версии

### Игрок

При первом `/start` бот просит игровой ник и сохраняет связь:

`telegram_id -> username -> game_nickname`

### Хранилище

Администратор:

1. открывает `📦 Хранилище`;
2. нажимает `➕ Принять предмет`;
3. выбирает игрока;
4. вводит название вручную или выбирает недавнее;
5. указывает количество;
6. добавляет комментарий или пропускает;
7. подтверждает запись.

Статус становится `🟡 На хранении`.

При выдаче бот просит подтверждение и меняет статус на `🟢 Выдано`, сохраняя дату и Telegram ID администратора.
