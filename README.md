# XZONA Group Bot v5 — роли, права и работа по темам

Версия v5 развивает предыдущий group-first бот: основные действия выполняются **прямо в темах Telegram-супергруппы**, а доступ к функциям определяется подтверждённой должностью игрока.

Личный чат с ботом по-прежнему нужен только для чувствительных данных Telethon (API HASH, код входа, 2FA) и некоторых старых служебных функций.

## Главное в v5

- профиль участника теперь содержит **игровой ник + должность + группировку**;
- формат в теме «Ники игроков» — две строки: `Ник` и `Должность`;
- права проверяются **при каждом нажатии кнопки/действии**, а не только при показе меню;
- Лидер и Заместитель лидера могут подтверждать запросы должностей через `/admin -> 🎖 Роли и доступ`;
- старому игроку можно назначить должность вручную ответом `/set_role ...` на его сообщение;
- представители других группировок после подтверждения роли могут **читать все темы**, но писать только в настроенной теме **General**;
- сообщения внешних лидеров/заместителей в рабочих темах автоматически удаляются ботом;
- тема «Ники игроков» остаётся узким исключением: внешний представитель может отправить там только корректную двухстрочную карточку профиля;
- «Снаряжение группировки» управляется Кладовщиком, Лидером и Заместителем;
- Рынком ГП и статусами заказов управляет Торговец, Лидер и Заместитель;
- обычный Рядовой может создавать заказы ГП и просматривать разрешённые данные;
- старая SQLite база v4 мигрирует автоматически.

## Поддерживаемые должности

### Полдень

- `Лидер`
- `Заместитель лидера`
- `Торговец`
- `Законодатель (Дипломат)` — также принимаются `Законодатель` и `Дипломат`
- `Кладовщик`
- `Командир ШО`
- `Рядовой`

### Представители других группировок

Поддерживаются Лидер и Заместитель для:

- Наёмников;
- Долга;
- Монолита;
- Греха;
- Ренегатов;
- Бандитов;
- Учёных;
- Свободы;
- Чистого Неба.

Примеры:

```text
Voron
Лидер Долга
```

```text
FreedomBoss
Заместитель Свободы
```

Допускаются варианты `Наемники/Наёмники`, `Ученые/Учёные`, а также `Заместитель лидера Долга`.

## Матрица прав v5

| Должность | Основные права в текущей версии |
|---|---|
| Лидер | все реализованные права |
| Заместитель лидера | роли, снаряжение, рынок, будущие управленческие модули; без секретов Telethon |
| Торговец | Рынок ГП, статусы заказов, будущий склад ГП |
| Законодатель / Дипломат | базовые функции участника + задел под дипломатию/новости |
| Кладовщик | приём, изменение и выдача снаряжения |
| Командир ШО | базовые функции + задел под мероприятия/цели |
| Рядовой | создание заказов ГП, просмотр разрешённого снаряжения |
| Внешний Лидер/Заместитель | чтение тем; писать можно только в General |

`ADMIN_IDS` и `OWNER_ID` остаются техническими суперпользователями для аварийного/первичного администрирования.

# Установка

Нужен Python 3.11+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

Linux/macOS:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

Создайте `.env` рядом с `bot.py`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789
OWNER_ID=123456789
DB_PATH=bot.db
```

Запуск:

```bash
python bot.py
```

## Права самого бота в Telegram

Бота рекомендуется сделать администратором группы и дать ему как минимум:

- доступ к сообщениям;
- **удаление сообщений** — обязательно для ограничения внешних представителей;
- при необходимости управление сообщениями/закреплениями.

Если у бота нет права удаления, программная проверка роли сработает, но он физически не сможет убрать сообщение внешнего представителя из чужой темы.

# Первичная настройка

## 1. Назначить General

Откройте тему **General** и отправьте:

```text
/set_general_topic
```

До выполнения этой команды модерация внешних представителей специально работает в безопасном режиме **fail-open**: бот ничего не удаляет, чтобы случайно не принять неправильную тему за General.

После настройки подтверждённые внешние Лидеры/Заместители:

- могут писать в General;
- могут читать остальные темы;
- их сообщения в других темах удаляются;
- в «Ники игроков» разрешена только корректная карточка профиля.

---

## 2. Настроить «Ники игроков»

В теме **Ники игроков**:

```text
/set_nicks_topic
```

Новый формат сообщения участника:

```text
Xan2795
Кладовщик
```

Для внешнего представителя:

```text
Voron
Лидер Долга
```

Бот связывает карточку с Telegram ID автора.

### Подтверждение должностей

Каждая должность, включая `Рядовой`, создаёт запрос на подтверждение. Лидер/Заместитель открывает:

```text
/admin
```

затем:

```text
🎖 Роли и доступ
```

и подтверждает или отклоняет запрос.

### Старые ники из v4 / старой истории

Исторические сообщения из одной строки по-прежнему импортируются через Telethon как ник, но **должность им не придумывается автоматически**.

Есть два пути:

1. игрок пишет новую карточку из двух строк;
2. руководство отвечает на любое его сообщение:

```text
/set_role Кладовщик
```

или, например:

```text
/set_role Лидер Долга
```

Снять должность:

```text
/clear_role
```

Команды `/set_role` и `/clear_role` нужно отправлять **ответом на сообщение нужного человека**.

---

## 3. Импорт старой истории через Telethon

Telethon подключается через:

```text
/admin -> 🔐 Telethon
```

Секретные данные вводятся только в личном чате владельца с ботом.

После подключения:

```text
/admin -> 👥 Ники игроков -> 🔄 Импортировать старые ники
```

Старые двухстрочные карточки тоже распознаются и попадают в очередь подтверждения, если такая должность ещё не была утверждена.

---

## 4. Снаряжение группировки

В нужной теме (на вашем скриншоте это **«Снаряжение группировки»**) отправьте:

```text
/set_storage_topic
```

Права управления:

- Лидер;
- Заместитель лидера;
- Кладовщик;
- технические `ADMIN_IDS`.

Обычные внутренние участники могут открывать разрешённый просмотр. Внешние представители не получают функциональных кнопок по правам, даже если видят сообщения темы.

Панель можно восстановить:

```text
/storage_panel
```

---

## 5. Рынок ГП

В теме **Рынок ГП**:

```text
/set_market_topic
```

Назначить получателя заказов можно ответом на сообщение Торговца:

```text
/set_gp_merchant
```

Управлять Рынком ГП могут:

- Лидер;
- Заместитель лидера;
- Торговец;
- технические `ADMIN_IDS`.

Внутренние участники с разрешением `market.create` формируют заказы прямо в теме. Внешние Лидеры/Заместители не могут создавать заказы через кнопки или через старое личное меню бота.

Статусы:

- 🟡 Ожидает Торговца;
- 🔵 Принят Торговцем;
- 🟣 Заказ собран;
- ✅ Выдан игроку;
- ❌ Отклонён.

# Что заложено на будущее

Роли уже используют отдельные permission-коды, поэтому следующие темы можно подключать без переделки профилей:

- `diplomacy.manage` — «Союзы и Война»;
- `events.manage` — «Мероприятия»;
- `targets.manage` — «Список целей»;
- `news.manage` — «Инфа в Зоне (Новости)»;
- `info.manage` — «Прочая информация»;
- `gp_stock.manage` — «Снаряжение ГП»;
- `delivery.manage` — «Пункт выдачи заказов».

То есть v5 — это уже основа для мультизадачного бота, а не отдельный модуль хранилища.

## Основные команды v5

```text
/set_general_topic   — назначить General
/set_nicks_topic     — назначить тему ников/ролей
/nicks_status        — состояние реестра
/set_storage_topic   — назначить тему снаряжения
/storage_panel       — показать панель снаряжения
/set_market_topic    — назначить Рынок ГП
/market_panel        — показать панель рынка
/set_gp_merchant     — назначить Торговца ответом на сообщение
/set_role <роль>     — вручную назначить роль ответом на сообщение
/clear_role          — снять роль ответом на сообщение
/my_role             — показать свой ник, подтверждённую и ожидающую роль
/admin               — управление группой, ролями и Telethon
```
