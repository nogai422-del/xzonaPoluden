# Изменения v7.3

- Добавлена полноценная кнопочная админка должностей после Telethon-импорта.
- Списки «Без должности», «Все игроки», «Заявки», поиск игрока.
- Назначение/смена/снятие роли одной кнопкой.
- Выбор внешней группировки и роли Лидер/Заместитель.
- Ограничение: Лидер 1, Заместитель лидера 5, остальные внутренние должности без лимита.
- Ограничения защищены на уровне БД и действуют для кнопок, /set_role и подтверждения заявок.
- В теме «Ники игроков» показывается динамический список доступных должностей.
- Заполненные ограниченные должности исчезают из публичного списка.
- Инструкция темы обновляется на месте без новых сообщений.
